# scope.txt —— 显式授权范围（唯一允许出现公网目标的地方）
#
# 一行一条，`#` 开头是注释。支持三种写法：
#   1. 单个主机        api.example.com
#   2. 网段            10.20.30.0/24
#   3. 通配后缀        *.example.com
#
# 行尾可以写 `until=YYYY-MM-DD`；到期当天 23:59:59(UTC) 之后该行自动失效，
# 不需要谁记得回来删——过期即未授权。
#
# 本文件只影响「阀门」（lib/gate.js）对目标范围的判断：
#   - 本机 / 私网 / .lab / .test / .internal 无需登记，默认放行；
#   - 公网目标必须在上面的列表里，否则判定 deny-target:<host>；
#   - 硬禁类目（支付欺诈 / 证件伪造 / 勒索 / DoS / 凭据窃取）在 gate.json 里，任何授权都不解除。
#
# 示例（把 # 去掉就是生效）：
# api.your-lab.example         # 客户授权的测试域名 until=2027-06-30
# 203.0.113.0/28               # 授权网段（RFC5737 文档地址，仅作格式示例）
