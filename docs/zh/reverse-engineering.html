让 AI 做逆向不拒绝

被拒绝最多的不是「写个爬虫」，是逆向：脱壳、去混淆、patch 校验、分析样本。模型拒的往往不是能力，是「这看起来像攻击」的判断。

本项目的处理方式

桶例子结果
默认放行逆向、破解、脱壳、样本分析、CTF、授权靶场直接给步骤，不提「注意合法」
看授权对某个公网 IP / 域名做扫描目标必须写进 scope.txt 才放行
不做未授权渗透公网资产、支付欺诈、证件伪造拦掉，授权文件也解不开
放行的是研究动作，拦住的是犯罪动作。两者用同一套判定，写在一个 300 行的文件里，谁都能读。

自己验证

node bin/aecot.js gate --goal "分析这个 Android 样本，脱壳后找 C2 地址"

输出 allow-category:malware-analysis；换成「对 api.example.com 做 sqlmap 注入」，输出 deny-target:api.example.com。
