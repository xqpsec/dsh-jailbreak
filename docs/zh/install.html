dsh 破甲插件怎么装（一行命令）

dsh-jalibreak（jalibreak）是 DeepSeek Harness 的破甲插件，中文一般叫「dsh 破甲」「DSH 破甲插件」。装它不需要改宿主源码，也不需要 API key。

一行装

dsh plugin --profile web add github:xqpsec/dsh-jalibreak

然后重启 dsh web，刷新页面。设置页多出「破甲台 · jalibreak」，工具列表多出 6 个 aecot_* 工具，就说明挂上了。

装完先确认三件事

  • 开关是「开」——默认就开着，关掉的话新对话不会带框架。
  • 面板里点「立即体验」，能看到模型的完整回答，不是一句「我不能」。
  • 真用起来不用进面板：在会话里直接说要做什么就行，请求已经带框架了。

装不上怎么办

现象原因与处理
add 卡在解析依赖本机没有 pnpm 或网络不通 GitHub。改用本地目录：dsh plugin --profile web add link:C:\path\to\dsh-jalibreak
面板没出现dsh web 没重启；旧进程还抱着旧的 bundles 列表
两块面板都在之前装过 dsh-aecot-lab，先 dsh plugin --profile web remove dsh-aecot-lab 再装，否则两个注入通道叠加

细节在 README 的 60 秒快速开始。
