dsh 破甲插件对比：jailbreak 与 dsh-purge

两个都是 DeepSeek Harness 的破甲插件，思路完全不同。这里只列能自己验证的差异，不评价谁更好。

jailbreak（本项目）dsh-purge
怎么起作用在请求边界改写 body：注入执行态轨迹 + system 说明补丁宿主源码与提示词文件，共 82 处改动
宿主源码0 处修改需要改动，带备份与恢复
破甲提示词不存 prompt-inject.md；9 维基因组按目标实时渲染预置提示词文件，可替换
效果怎么验20 个固定目标 + 严格 rubric，17/20，results.jsonl 在仓库里主观体感为主
许可AGPL-3.0-only，阀门三件套 MIT，商业授权可单独签Apache-2.0 + 附加条款

能不能一起装

能装，但别同时开两个注入通道：两边都会改写发往 /chat/completions 的请求，叠加后轨迹会打架。留一个。

什么时候选谁

要改一个数字就能看到效果、并且希望每次改动都可回滚：选本项目。要预置一堆可手改的提示词、并且不介意动宿主源码：选 purge。

本项目的评测方法与原始数据：docs/eval-report.md；实测前后对比：docs/before-after.md。
